+# SVCS वेबसाइट — सुरक्षित डेटा स्टोरेज एवं एडमिन पोर्टल सेटअप
+
+इस वेबसाइट में ID Card आवेदनों का डेटा सुरक्षित रखने और एडमिन पोर्टल चलाने के लिए **Google Sheets + Google Apps Script** (बिलकुल मुफ़्त) उपयोग होता है।
+
+## फ़ायदे
+- डेटा आपके **अपने Google अकाउंट की Sheet** में — किसी और के पास नहीं
+- **ID + Password** सिर्फ Apps Script की सुरक्षित Script Properties में — वेबसाइट कोड में कभी नहीं
+- फोटो आपके **Google Drive फोल्डर** में
+- ग्राहक को **ईमेल पर ID Card PDF** — आवेदन के साथ पावती और स्वीकृति के बाद हस्ताक्षरित PDF
+- एडमिन पोर्टल से **स्वीकृत / अस्वीकृत** और **हस्ताक्षरित PDF भेजना**
+
+## स्टेप-दर-स्टेप (15 मिनट)
+
+### 1. Google Sheet बनाएँ
+- https://sheets.google.com खोलें → नई Sheet बनाएँ → नाम दें `SVCS ID Card Data`
+
+### 2. Apps Script जोड़ें
+- Sheet में **Extensions → Apps Script** खोलें
+- जो कोड मिले उसे हटाकर इस रिपॉजिटरी का **`backend/Code.gs`** पेस्ट करें
+- 💾 Save करें
+
+### 3. एडमिन ID/पासवर्ड सेट करें (सुरक्षित जगह)
+- Apps Script में **Project Settings (⚙️) → Script Properties → Add script property**:
+  - `ADMIN_USER` = अपना एडमिन ID (जैसे: `svcsadmin`)
+  - `ADMIN_PASS` = मज़बूत पासवर्ड (जैसे: `Svcs@2026#Admin`)
+  - `NOTIFY_EMAIL` = आपका ईमेल (नए आवेदन की सूचना हेतु)
+
+### 4. Deploy करें
+- **Deploy → New deployment → Web app**
+- Description: `SVCS ID API`
+- **Who has access: Anyone** चुनें
+- **Deploy** → अनुमति माँगे तो **Authorize** करें (अपने ही Google अकाउंट से)
+- जो **Web app URL** मिले उसे कॉपी करें
+
+### 5. वेबसाइट में URL डालें
+- `config.js` में `APPS_SCRIPT_URL: ''` के उद्धरण चिह्नों के बीच वह URL पेस्ट करें
+- बस! अब सब कुछ असली सुरक्षित मोड में चलेगा
+
+## एडमिन पोर्टल उपयोग
+- वेबसाइट में **admin.html** खोलें (फुटर का "एडमिन लॉगिन" लिंक)
+- Step 3 में बनाए **ADMIN_USER / ADMIN_PASS** से लॉगिन करें
+- डैशबोर्ड में दिखेगा: **कितने ID Card बने**, कितने लंबित, स्वीकृत, अस्वीकृत
+- हर आवेदन पर: **✅ स्वीकृत / ❌ अस्वीकृत / ✍️ हस्ताक्षरित PDF भेजें**
+
+## जब तक Apps Script नहीं जोड़ा...
+वेबसाइट **डेमो मोड** में चलती है (सब कुछ आपके ब्राउज़र में ही)।
+डेमो एडमिन लॉगिन: `admin` / `svcs@2026` — यह केवल परीक्षण हेतु है।
+
+## सुरक्षा सुझाव
+- `ADMIN_PASS` कभी किसी को WhatsApp/ईमेल पर न भेजें
+- समय-समय पर पासवर्ड बदलते रहें (Step 3 से)
+- Google Sheet को **केवल अपने अकाउंट** तक सीमित रखें (Share में किसी को न जोड़ें)
+- जिन सदस्यों का डेटा हटाना हो, Sheet की पंक्ति हटा दें + Drive फोल्डर से फोटो हटाएँ
